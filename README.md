# Airline Booking Predictor — British Airways

Predicting whether a customer completes a flight booking, and analysing what
Skytrax reviewers say about the airline. Built as part of the British Airways
Data Science virtual experience programme (Forage).

The project has two independent halves that share a pipeline runner:

1. **Review mining** — scrape and analyse customer reviews (unstructured text)
2. **Booking prediction** — model booking completion (structured tabular data)

---

## Pipeline

| Stage | Module | What it does |
|---|---|---|
| 1. Scrape | `web_scraper.py` | Pulls British Airways reviews from Skytrax (airlinequality.com) with `requests` + `BeautifulSoup`. Paginated, rate-limited with a 1.5s delay, de-duplicated. Writes `british_airways_reviews.csv` with title, body, rating, review length, timestamp, source and airline. |
| 2. Analyse | `nlp_analysis.py` | Cleans and lemmatises the review text with NLTK (lowercasing, special-character stripping, tokenisation, custom airline stop-words). Scores sentiment with VADER and buckets each review from Very Negative to Very Positive. Extracts themes with LDA topic modelling over a CountVectorizer/TF-IDF document-term matrix. Outputs sentiment distributions, compound-score histograms, per-topic top words and word clouds. |
| 3. Model | `booking_prediction.py` | Trains a `RandomForestClassifier` (100 estimators) on `customer_booking.csv` — 50,000 booking records across 14 features — to predict `booking_complete`. `flight_day` is mapped to 1–7; `sales_channel`, `trip_type`, `route` and `booking_origin` are label-encoded. |
| 4. Evaluate | `booking_prediction.py` | Reports accuracy, AUC-ROC, a full classification report and 5-fold cross-validation (mean ± std), then plots feature importances and the ROC curve. |
| Runner | `main_pipeline.py` | Orchestrates the stages end to end. |

### A note on the evaluation

`booking_complete` is heavily imbalanced — most sessions do not end in a booking —
so **accuracy alone is misleading**: predicting "no booking" every time already
scores highly. AUC-ROC, the per-class precision/recall in the classification
report, and the cross-validated spread are the numbers that actually describe the
model, which is why all of them are reported rather than a single headline figure.

## Getting the data

`customer_booking.csv` is supplied by the Forage programme and is **not committed
to this repository**. Download it from the virtual experience and place it in the
repository root before running the model.

The review CSV is generated by running the scraper — no manual download needed.

## Setup

```bash
git clone https://github.com/Khush430/Airline_Booking_Predictor.git
cd Airline_Booking_Predictor

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

NLTK needs its corpora on first run:

```python
import nltk
nltk.download('punkt')
nltk.download('stopwords')
nltk.download('wordnet')
nltk.download('vader_lexicon')
```

## Running it

```bash
python web_scraper.py        # 1. collect reviews  -> british_airways_reviews.csv
python nlp_analysis.py       # 2. sentiment + topics
python booking_prediction.py # 3 & 4. train and evaluate the model

python main_pipeline.py      # or run the whole thing at once
```
